Albumen 1.1.5 - Windows 11 x64

Starting Albumen
Extract the complete ZIP to a local folder, keep its files together, and run
Start-Albumen.cmd. It checks the packaged files, then starts the app.
Nothing needs to be installed: the .NET runtime and the image model are
included in this folder.

Windows SmartScreen and Smart App Control
This build is not code-signed, so Windows may show "Windows protected your
PC" the first time. Choose "More info", then "Run anyway". If Windows blocks
the extracted files, right-click the ZIP before extracting, open Properties,
tick "Unblock" and extract again. On a PC with Smart App Control turned on,
Windows blocks the app and offers no way to run it.

Using it
Choose one local folder and scan it. Review shows identical copies,
look-alikes and photos the image model finds similar, set by set; type a few
words in the search bar to find photos by what they show. Mark the photos
you want gone. Only the photos you approve are moved to the Recycle Bin, one
at a time, and at least one photo in every set is always kept. Restore
anything from the Recycle Bin if you change your mind.

Albumen processes your photos locally and never uses the network. No
account, install, or download is required. Its own data is kept in
%LOCALAPPDATA%\Albumen.

Do not edit or replace packaged files: verification rejects changes. See
THIRD-PARTY-NOTICES.md for the components included in this release.
